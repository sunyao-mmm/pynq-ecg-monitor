# Build

| 文件 | 用途 |
|---|---|
| `pulsecore_project.zip` |本项目的顶层工程中例化了 `clt_qrs`（曲线长度变换 QRS 检测）模块。由于该模块改编自第三方开源仓库（原作者未提供 LICENSE），为了尊重原作者版权，本公开仓库工程压缩包，因此直接运行 `rebuild.tcl` 可能会提示找不到该模块。完整的压缩包已打包作为附件直接提交给大赛组委会，仅供评审使用。目前我们正在联系原作者获取授权，若获得授权，后续会补充该工程压缩包。|
| `rebuild.tcl` | 自动生成输出产物、综合、实现并导出硬件文件 |
| `timing.rpt` | 最终实现的时序摘要 |
| `util.rpt` | 最终实现的资源占用摘要 |
| `README.md` | 本目录解压和重建说明 |
